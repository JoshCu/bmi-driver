# bmi-driver (Python)

Python bindings for [bmi-driver](https://github.com/JoshCu/bmi-driver): drive C, Fortran and
Python BMI models through one interface, and read the driver's NetCDF forcings.

```bash
pip install maturin
maturin develop -m crates/bmi-py/Cargo.toml
```

See the repository's `docs/python.md` for the full API.
